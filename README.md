## 📖 Quick Start Guide

### Prerequisites
- **Node.js** 18+ (LTS recommended)
- **npm** atau **yarn**
- **PostgreSQL** 12+ (untuk proyek backend dengan database)
- **Git**

### Frontend Projects

#### 1) Bookshelf App (Vanilla JS)
```bash
cd belajar-membuat-frontend-web-untuk-pemula/bookshelf-app-starter-project
# Buka index.html di browser (atau gunakan Live Server)
```

#### 2) Notes App (React - Dasar)
```bash
cd belajar-membuat-aplikasi-web-dengan-react
npm install
npm run dev
# Buka http://localhost:5173
```

#### 3) Notes App (React - Advanced)
```bash
cd belajar-fundamental-aplikasi-web-dengan-react/submission-1
npm install
npm run dev
# Buka http://localhost:5173
```

### Backend Projects

#### 1) Bookshelf API (In-Memory)
```bash
cd belajar-backend-pemula-dengan-javaScript
npm install
npm run start
# Server: http://localhost:9000
```

**Development mode**:
```bash
npm run start-dev  # dengan nodemon
```

#### 2) OpenMusic API (PostgreSQL)

**Setup Database**:
```bash
# Login ke PostgreSQL
psql -U postgres

# Buat database dan user
CREATE DATABASE openmusic;
CREATE USER developer WITH ENCRYPTED PASSWORD 'supersecretpassword';
GRANT ALL PRIVILEGES ON DATABASE openmusic TO developer;
\c openmusic
GRANT ALL ON SCHEMA public TO developer;
\q
```

**Setup Project**:
```bash
cd belajar-fundamental-backend-dengan-javaScript
cp .env.example .env
# Edit .env sesuai kredensial database Anda

npm install
npm run migrate up    # Jalankan migrations
npm run start         # Server: http://localhost:5000
```

**Development mode**:
```bash
npm run start-dev  # dengan nodemon
```

## 📝 Catatan & Tips

### Database Setup
- Untuk proyek dengan PostgreSQL, **jalankan migrations** sebelum start server:
  ```bash
  npm run migrate up
  ```
- Jika ada error permission, pastikan user database punya privilege pada schema `public`

### Environment Variables
- **Jangan commit file `.env`** ke repository
- Gunakan `.env.example` sebagai template
- Update kredensial sesuai setup lokal Anda

### Development Workflow
- Backend: Gunakan `npm run start-dev` untuk auto-reload dengan nodemon
- Frontend: Vite dev server sudah include hot module replacement (HMR)

### Code Quality
- Semua proyek menggunakan **ESLint** dengan Airbnb style guide
- Jalankan `npm run lint` sebelum commit
- Pastikan tidak ada unused imports atau variables
